# Teto Desk 0.1.21

- 面向新用户的本地客户端检测：仅ChatGPT、仅DeepSeek以及双通道配置。
- 不显示未发现的CLI选项，保存并验证当前用户的客户端路径，支持手动定位和重新检测。
- ChatGPT显示5小时/周额度；DeepSeek显示账户余额与峰谷期；查询随当前服务切换。
- 默认使用可写的用户数据目录，提供portable.flag便携模式。
- 新的允许清单打包和隐私扫描，发布包不含个人设置、会话、附件、客户端、账户或测试日志。
- MIT代码许可、独立素材及依赖声明，保留当前透明图标和全部已批准动画。

Windows 10/11 x64，.NET Framework 4.8。需安装并登录Codex CLI或官方DeepSeek Harness Desktop之一。完整解压运行包；源码ZIP包含可编辑工程。客户端登录和模型可用性由其自身决定，本发布不包含或要求API Key。
