# Teto Desk 0.1.21 artwork sources

This folder contains the current application's native Aseprite projects and generated atlases/configuration. Artwork scope is documented in ../ARTWORK.md. The code's MIT license does not grant character or third-party rights.

Aseprite工程 contains 13 projects matching the bundled animations. The angry project is the source actually embedded in this release; unpublished local edits and the original full reference sheet are not distributed. 合并png contains the five current transparent atlases; 动画配置 contains the five corresponding JSON manifests. 其他资源/程序图标 contains the transparent portrait master and the multi-size ICO.

The authoritative build resources are ../src/Assets. Re-export and validate native pixels/timings before replacing them. Editing a native project alone does not change the compiled executable. Animation previews and historical exports are intentionally not included.
